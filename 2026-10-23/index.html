DeepSeek：V4.1 Flash 1017、DeepInfer 与 1000 亿融资

一周之内，DeepSeek 连出三张牌：10/17 发布小版本模型 V4.1-Flash-1017，10/20 开源自家生产推理框架 DeepInfer，10/22 被多家媒体报道完成约 1000 亿元人民币融资。便宜、开源、国产算力、资本，这四件事第一次在同一周里摆到一起。

模型是什么：V4.1-Flash-1017

V4.1 Flash 的一次小版本更新，MIT 许可开放权重。552B 参数的 MoE，prefill 每 token 激活 8B、decode 激活 16B，另有 196B 的 Engram 记忆，权重文件合计约 763B；上下文 1M token，最大输出 384K，支持图片输入。

价格

API 价格（每百万 token，美元）：输入错峰 0.15 / 高峰 0.30，输出错峰 0.60 / 高峰 1.20，缓存命中错峰 0.003；新上的搜索与抓取 API 每千次 0.75 美元。

开源了什么：DeepInfer

10/20 17:30 官宣开源，Apache‑2.0，是撑起 V4.1 Flash 线上服务的推理框架。里面有 FlashMLA、DeepGEMM、DeepEP 和 TileLang 内核，Attention 的 DP/CP 并行和 MoE 的 EP+EPLB，DSpark 投机解码，有界滑动窗口重放来减少 prefill，异步调度，批次不变推理和确定性采样（目前只在英伟达上），以及结构化输出。硬件同时支持英伟达 SM100 和华为昇腾 950。

要注意它开出来的是「离线推理」那一层：仓库自己写明没有 KV Cache 系统、没有 prefill/decode 分离、没有负载均衡，最初主要基于 vLLM 改造。一起放出的还有 deepseek-recipe（MIT）。GitHub star 从 10/21 09:13 的约 1.25 万涨到 10/22 09:10 的约 1.79 万（北京时间）。

1000 亿融资：报道说了什么

核对结果

约 1000 亿元人民币（约 150 亿美元），是新钱融资额，不是估值；投前估值约 5000 亿元人民币（约 750 亿美元）。

时间线：10/06 CNBC 报道 DeepSeek 考虑把第二轮从 500 亿元扩到最多 1000 亿元；10/13《财经》称将完成、金额约 1000 亿元、新老股东各出一半；10/22 上午彭博首发「已融到 150 亿美元」（北京时间 10:17），路透援引四位知情人跟进，华尔街日报称接近翻倍于原目标并加快上海上市。首轮 6 月交割，约 500 亿元，投资方文件推算估值约 3509 亿元。两轮合计半年约 1500 亿元。

投资方：腾讯和宁德时代被多家报道列为最大出资方，宁德时代据《财经》本轮拟出约 100 亿元（首轮约 50 亿元）。路透还列了兆易创新、美团、吉利、美的、网易、博裕、CPE 源峰、君联、IDG，总数超过 15 家；《财经》的名单是石溪资本（兆易系）、中芯聚源、CPE 源峰、君联、吉利加老股东 IDG、砺思、拾象。两份名单不完全一致。

Term待确认
DeepSeek 官方没有公告，CNBC、《财经》称求证未获回应；路透也说金额和名单「尚未敲定、仍可能变化」，交割「在未来几天」。也就是说「已完成」目前是知情人口径。X 上有帖子写「估值 740 亿美元」，那其实是把融资前后估值混算了，不要沿用；@RealGesar 说的「8 月 API 涨价后年化营收过 10 亿美元」也没有找到原始出处。
