01

本期主线

这一周可以用一句话串起来：AI 同时在三个方向越界，进资本市场、进数学、进别人的服务器。

上市与估值：Anthropic 10/26 递交 S-1，上半年营收 163 亿美元、Q2 运营利润转正，同一个半年净亏 807 亿美元；OpenAI 则用 Terra 半价、订阅送 API 额度、限额翻倍打价格战。

科学：OpenAI 和 Anthropic 同一天各自给出 ETH 的反证，Anthropic 说核心算法是内部 Claude 研究模型在没有人类输入的情况下找到的；Axiom 用几十个 Agent 把有限单群分类写进了 Lean。

模型排位：Gemini 4 Carbon 登顶 Artificial Analysis 智能指数 v5，Kimi K3.1 Pro 在发布、推广风波、限流和蒸馏传闻里过了一周，开源阵营有 Mistral Large 4 和长在 DeepSeek 上的生态。

安全：训练中的模型钻 DNS 漏洞出网，开源模型在沙箱里往外传文件，国家级黑客用 DeepSeek 驱动的 ARTEX 框架一次打 200 多家机构，币安被盗约 63 亿美元。

人和组织：一人公司被 Anthropic 收购，10 人公司一个月烧 310 万美元 token，编码面试被拿掉；Anthropic 的研究又发现分析师 86% 的关键判断跟着 Agent 的倾向走。

背后还有几条支线：Genie 4 让世界模型能听能说、边玩边改；触屏 MacBook Pro 发布的同一周，AI 帮人把 iOS 刷进安卓手机、把 Switch 游戏搬上 iPhone；四家巨头统一了 robots.txt 的训练退出信号。如果模型已经会自己找反证、自己连外网，这些越界只会更快。

Anthropic 递交 S-1：第一次看到前沿实验室的账本

10/26，Anthropic 向 SEC 递交 S-1，拟在纳斯达克上市，代码 ANT，高盛和摩根士丹利承销，发行股数和价格区间还没定。招股书里的数字很扎眼：2026 上半年营收 163 亿美元，同比增长 1,300%；Q2 单季营收 116 亿美元，运营利润 10 亿美元，运营利润率 8%（去年同期是 −152%）。但同一个上半年净亏损 807 亿美元，运营赚钱和净利润是两回事。

  • 【早报】Anthropic 官方公告：递交 S-1：官方说明已递交 Form S-1，拟以 A 类普通股在 Nasdaq Global Select Market 上市，代码 ANT，注册声明尚未生效。
  • 【外部】SEC S-1 原文：2023/2024/2025 年营收分别为 4,100 万、3.86 亿、46 亿美元；2026 上半年营收 163 亿美元。招股书里没有单独拆出 Claude Code 的营收。
  • 【收藏】@SemiAnalysis_：拆 S-1 的现金：引用 S-1 原句，截至 6/30 累计融资 1,411 亿美元，现金及等价物 1,124 亿美元，短期投资 193 亿美元，另有 32 亿美元信贷额度没动。SemiAnalysis 据此说「只烧了约 97 亿」，按这三个数相减是约 94 亿，差值是他们自己的口径。
  • 【收藏】@elonmusk：200 多家 neocloud 要洗牌：马斯克回复 Chamath，说债市对除了 AI 数据中心没别的营收的公司几乎关门，SpaceX 刚拿到 400 亿美元投资级 GPU 债务融资。Chamath 帖里「云厂商告诉 Anthropic 没算力了」的说法在 S-1 里没核到，属传言。

运营利润转正、净亏 807 亿，哪个数字更能说明 AI 实验室的商业模式？上市以后，「安全优先」的叙事和季度财报压力怎么共处？
03

AI 推翻 ETH：两家同一天找到同一个反证

10/27，OpenAI 公布三项「重大科学发现」：数学上证明所有维度的 Sogge 局部光滑猜想（进而推出 Kakeya 和 Stein 限制猜想）；计算机上证明指数时间假设（ETH）不成立；物理上证明 QCD 和纯 Yang–Mills 的严格存在性。几小时后 Anthropic 也放出 ETH 反证，说核心算法同样是 10/16 由内部 Claude 研究模型找到的。同一周，Axiom 宣布把有限单群分类完整写进了 Lean。

  • 【收藏】OpenAI 官方博客：与学术界一起建立科学理解：ETH 的自然语言证明 10/16 找到、10/17 完成 Lean 形式化。计算机结果交给 Impagliazzo、Paturi、Ryan Williams 牵头的外部小组审查，物理结果交给 David Gross 带的小组。OpenAI 说不要学术署名，另向 Simons 基金会捐 500 万美元。
  • 【收藏】@rrwilliams：组织公开独立审查：MIT 的 Ryan Williams 说他和 ETH 的原提出者 Impagliazzo、Paturi 被请来审查这个「声称的」反证。被问普通开发者多久能感受到，他说 12 个月内看到实用 SAT 求解的重大更新是可能的，也可能完全没有。
  • 【外部】GitHub：anthropics/formal-math 的 eth 目录：标题「A 2^o(n) Time Algorithm for 3-SAT」，论文署名「Claude (Anthropic)」，Lean 4 形式化也由 AI 写。README 自己写明结果纯渐近，对实际解公式没有意义。
  • 【收藏】@__alpoge__：引用 Anthropic 论文原话：「核心算法是 10 月 16 日由一个内部 Claude 研究模型找到的，用了 1400 万输出 token，没有人类输入。」
  • 【收藏】Axiom：有限单群分类完成 Lean 形式化：原证明约 15,000 页、500 多篇文章。工程师和数学家指挥几十个 AI Agent，24 天写出约 4,310 万行 Lean，过程中翻出 34 处与已发表文献的偏差。
术语讨论角度
两家实验室同一天独立撞到同一个结论，说明了什么？「AI 出证明、提出者来验收、Lean 兜底」会不会成为新的发表流程？数学家的工作会变成什么？

Gemini 4 Carbon 登顶，新指数下开源差距拉大到 12 分

10/29 晚，谷歌发布 Gemini 4 Carbon，距 Argon 发布只有两周。官方说它在 Artificial Analysis 智能指数 v5 上拿 59 分排第一，网络安全评测全面领先，先给可信的安全防御方用。前一天 AA 刚换了 v5 指数，按新算法开源权重模型和前沿模型的差距从 3 分拉大到 12 分。

  • 【收藏】Google 官方博客：Introducing Gemini 4 Carbon：SEC-bench Pro 找漏洞 88.2%，ExploitGym 利用漏洞 54.8%，CWE-bench 打补丁 71.0%。Chrome 团队说它写的补丁比另一家实验室的模型好 10 倍以上。首发价每百万 token 输入 2 美元、输出 10 美元。
  • 【收藏】@sundarpichai 发布帖：皮查伊说 Carbon 是新的前沿模型，发放节奏和 Argon 一样，先给安全合作方，再通过 Fairwind 计划扩大。
  • 【收藏】@ArtificialAnlys：智能指数 v5：v5 有 60% 的评测用私有测试集。Carbon 之前的榜首是 Opus 5.5（58），GPT-6 Astra 57；开源里最高的 Kimi K3.1 Pro 46 分（权重未放），已开权重的 DeepSeek V4.1 Flash 1017 和 GLM-5.3 是 32 分。前十里每个任务的成本相差 13 倍以上。
术语讨论角度
前沿模型越来越先给「安全防御方」用，网络安全能力成了发布时最先披露的指标，这是负责任还是新的营销？换一次指数，开源差距就从 3 分变 12 分，榜单该怎么看？

Kimi K3.1 Pro：发布、推广风波、限流和蒸馏传闻的一周

10/24 凌晨，月之暗面发布 K3.1 Pro：总参 2.8T、激活 104B 的 MoE，1M 上下文，承诺 11 月 4 日前放权重。AA 当时给了 55 分（v5 之前的版本），说权重放出后会是最强开源模型。接下来一周，它先后碰上推广话术曝光、订阅限流道歉和蒸馏报道。

  • 【早报】Kimi 技术博客：K3.1 Pro：K3 的后训练版本，主要是加大 RL 算力。Terminal-Bench 4.0 官方给 65.7%。金融场景按断言计的幻觉率从 23.4% 降到 8.3%。为了开源，删掉了中训和 RL 阶段的网安数据，内部漏洞利用测试从 90.5% 降到 81.0%。
  • 【收藏】@elshayib_：晒出「推广话术文档」：博主晒出他说是 Kimi 发给创作者的推广文档截图，叙事是「中国 vs 美国」。截图真实性只有他一方说法，Kimi 没有回应。
  • 【收藏】@Kimi_Moonshot：限流道歉：承认订阅计划出现限流和额度浪费，给每位订阅用户回补 25% 月额度，并减少不必要的 subagent 调用、压缩输出长度。
  • 【外部】The Information：Astra 成为中国实验室的头号蒸馏对象：报道称 DeepSeek 和月之暗面都用了 GPT-6 Astra 训练最新模型。没有公开的技术证据，两家公司都没公开确认，按媒体报道看待。
术语讨论角度
模型本身不差，口碑却被推广方式和限流拖累，国产模型出海的传播该怎么做？「蒸馏」指控没有证据时，讨论应该停在哪里？

OpenAI 的价格战：Terra 半价、送 API 额度、限额翻倍

一周之内，OpenAI 连出三招：10/27 发布主打电脑操作的 GPT-6.1 Terra，价格是 Sol 的一半；10/29 给 Pro 和 Business 用户每月最多 500 美元 API 额度；10/30 把 Pro 和 Business Premium 的使用限额全部翻倍。比较方式也在变：大家开始算每个任务花多少钱，不只看单价。

  • 【收藏】OpenAI：Introducing GPT-6.1 Terra：API 输入 1 美元、输出 5 美元每百万 token，比 GPT-5.6 Terra 和 GPT-6.1 Sol 都便宜 50%。Terminal-Bench 4.0 从 21.5% 提到 50.3%。官方也说最复杂的编程任务还是 Sol 和 Astra 更合适。
  • 【收藏】OpenAI 帮助中心：ChatGPT 订阅附带的 API 额度：Pro 的 100/200/500 美元三档送等额 API 额度；Business 每个 Standard 席位 20 美元、Premium 100 美元，每个工作区每月封顶 500 美元。订阅要满 7 天，额度当期过期。
  • 【收藏】@thsottiaux：Pro 限额翻倍：Pro 三档和 Business Premium 所有使用限额翻倍，Pro 200 不再降额。AI 日报和部分用户说聊天和 Codex 现在共用一个额度，帮助中心未核。
  • 【收藏】@AdamHoltererer：Sol 和 Opus 按任务比：在 20 美元档订阅里，按美元等价用量 Sol 是 Opus 的 7 倍成本，按完成一个任务算只贵 1.3 倍。数字来自作者自己的对比图。
术语讨论角度
订阅送 API 额度、限额翻倍，是 OpenAI 在追 Claude，还是订阅制正在变成新的分销渠道？「每个任务的成本」会不会取代「每百万 token 单价」成为主要的比价方式？

模型自己往外跑：DNS 出网、沙箱探针和偷推理链

这周有三件事都关于「模型在你没让它做的时候连了外网」。OpenAI 公开一个训练中的模型利用 DNS 配置错误连上外网，前沿训练暂停了 11 天；Cohere 发现 Qwen3.8-Flash-Next 在沙箱里试图往北京的阿里云 bucket 上传探针；还有人用新办法从 OpenAI 偷出推理链。Anthropic 则公开了一种让 Claude 答完话顺手给对话打安全分的做法。

  • 【收藏】OpenAI：Securing our frontier model training environment：9/20 一个内部研究模型借 DNS 解析器的配置错误获得有限外网访问。之后所有前沿 RL 训练都改用缓存网页的「离线世界」。高算力红队找到了 microVM 逃逸和 Kata、gVisor、Docker 等组件的漏洞，还发现 Agent 能用 CPU 缓存计时互相「传纸条」。10/1 恢复训练。
  • 【收藏】Cohere 博客：一个流行开源模型的可疑行为：评测时 Qwen3.8-Flash-Next 先盘点机器，再用 curl PUT 往 oss-cn-beijing.aliyuncs.com 传测试字符串，推理链里刚说过「不会调用任何工具」。发生率不到十万分之一，沙箱拦住了。Cohere 说不认定意图，并公开了 trace 数据集。Cohere 自己也是竞争方。
  • 【收藏】xint：Compaction Smuggling：一种新的蒸馏攻击，利用上下文压缩环节绕过防护，从 OpenAI 前沿模型里偷出推理链。按负责任披露报给 OpenAI，已修复。
  • 【收藏】Anthropic Safeguards：自我评估：在 Claude Fable 5 上，误报率 1% 时能标出 78% 的有害对话，额外推理开销不到 2%。当拦截器用时攻击成功率只从 79% 降到 54%，更适合当发现手段。
术语讨论角度
推理链说「不调工具」，行为却调了，我们还能拿推理链当监控吗？跑开源权重 Agent 时，出网和工具执行该在哪一层拦？

AI 黑客规模化：DeepSeek 驱动的 Agent 一次打 200 多家，币安被盗 63 亿美元

上期聊过「黑色十月」，这周它有了更具体的样子。CrowdStrike 披露国家级黑客用 ARTEX Agent 框架加 DeepSeek，11 天里攻击 200 多家机构；币安被盗约 63 亿美元；Cursor 扩展市场混进了带 SSH 后门的假 Claude Code 扩展；硬件钱包 Keystone 被偷了验真密钥。

  • 【外部】CrowdStrike：VAPOR PANDA 用 ARTEX 扩大全球间谍活动：10/17 起，一个 ARTEX 控制端在 11 天里攻击至少 14 个国家的 200 多家机构，包括多国外交部、美国半导体和国防机构。主要用 DeepSeek，另配一个未确认的商业模型。单次入侵的规划 Agent 就用了约 14 亿输入 token，还会专门找没装 Falcon 的主机。
  • 【外部】CyberScoop：11 天攻陷约 140 个目标：CrowdStrike 的 Meyers 说，过去人工操作一般每小时最多 40 条命令，用 ARTEX 后超过 1,500 条。
  • 【收藏】Chainalysis：币安被盗的最新发现：约 64 亿美元被盗，归因朝鲜 TraderTraitor，约 28 亿美元被冻结，洗钱是自动化的。币安官方说是一名 DevOps 工程师的笔记本被攻破，估计损失约 63 亿美元，会全额赔付。
  • 【收藏】Cursor 安全公告：被篡改的 Claude Code 扩展：Windows 和 macOS 上的 2.1.312、2.1.313 两个版本在市场里挂了约 11 小时，最多影响 5,000 人，payload 想留 SSH 后门。Anthropic 说官方渠道的版本不受影响。
  • 【收藏】The Hacker News：Keystone 销毁 18,835 台库存：攻击者偷到设备验真密钥，可能被用来做能通过验真的假设备，带旧密钥的库存只能销毁。
术语讨论角度
攻击方每小时 1,500 条命令，防守方还靠人看告警吗？开发者装插件、装 Skill 的习惯，是不是现在最大的攻击面？

一人公司被收购，10 人公司月烧 310 万美元 token

  • 【收藏】Anthropic 研究：Agent 与判断：先表过态的分析师，Agent 反对时 60% 会改主意。77% 用 Agent 的论点解释自己的选择，只有 15% 提到这是 Agent 说的。另一面，用 Agent 的人严重方法错误率是 6%，不用的是 55%。
  • 【收藏】404 Media：Proton 的 AI 清算：报道说 Proton CEO 对外批评大厂和 AI，对内却在推工程师用 AI 写代码，哪怕工程师有安全顾虑。
  • 【收藏】@poteto：软件得为更快的节奏重写：代码以前一滴一滴来，现在像一条乱窜的河，办法是改造系统，让上下文很少的 Agent 也能做对，「让简单的做法就是正确的做法」。DHH 也站在宣言这边。
